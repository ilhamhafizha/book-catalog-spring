## 🛠️ Tech Stack & Versi

* **Java Version**: 25
* **Spring Boot**: 4.1.1
* **Build Tool**: Maven
* **Group ID**: `com.hamfizh`
* **Artifact ID**: `book-catalog`

---

## 📦 Dependensi Utama

Proyek ini menggunakan dependensi berikut (didefinisikan di `pom.xml`):

* **`spring-boot-starter-webmvc`**: Modul utama untuk membangun web/REST API dan fitur data binding.
* **`spring-boot-devtools`**: Modul pengembangan untuk fitur *fast application restarts* dan *live reload*.
* **`spring-boot-starter-webmvc-test`**: Modul pengujian (testing) untuk layer Web MVC.
